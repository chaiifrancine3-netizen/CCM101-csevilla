

# Laboratory Activity 9

## Mission 9: The Cloud Automation Engineer

### Mission Overview

This laboratory activity focuses on Bash scripting, automated backups, Linux file permissions, and Cron job scheduling.

### Objectives

- Understand Bash scripting.
- Create and execute automation scripts.
- Use variables in Bash.
- Apply executable permissions using chmod.
- Create compressed backups using tar.
- Configure Cron jobs for automatic scheduling.
- Document automation procedures using Markdown.

### Commands Executed

| Command | Description |
|---|---|
| `pwd` | Displays current directory. |
| `mkdir app-data` | Creates application folder. |
| `echo` | Creates a sample data file. |
| `nano backup.sh` | Creates the backup script. |
| `chmod +x backup.sh` | Makes the script executable. |
| `./backup.sh` | Executes the backup script. |
| `ls -l backups/` | Displays backup files. |
| `tar -tzf` | Lists compressed backup contents. |
| `crontab -l` | Displays Cron jobs. |
| `crontab -e` | Edits Cron configuration. |

### Skills Learned

- Bash Shell Scripting
- Linux File Permissions
- Automated Backup
- File Compression
- Cron Job Scheduling
- Linux Command-Line Operations
- Cloud Automation
