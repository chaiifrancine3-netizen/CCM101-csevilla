
# Checkpoint 2 – Research: The Language of Automation

## 1. Bash Script

A Bash script is a file that contains Linux commands that can run automatically. The `#!/bin/bash` line is called a shebang, which tells Linux to use the Bash shell to execute the script.

## 2. Variables

Variables store information such as folder names, file paths, and values. They make scripts easier to manage because we can change information in one place instead of typing it repeatedly.

## 3. Cron Job

A Cron job is a Linux feature that automatically runs commands or scripts at a scheduled time. It is useful in cloud operations because it automates regular tasks such as backups and system maintenance.
