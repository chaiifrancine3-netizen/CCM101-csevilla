
# Checkpoint 7 – Mission Reflection

Throughout Laboratory Activities 1 to 9, my understanding of Cloud Computing has improved. At first, I only knew that cloud computing was about storing files and accessing services through the internet. As I completed each laboratory activity, I learned that it also involves managing infrastructure, deploying applications, securing systems, monitoring resources, and automating tasks.

Automation is important when managing hundreds of cloud servers because it saves time and reduces repetitive manual work. Instead of performing the same task on every server, administrators can use scripts to execute commands automatically. However, automation also has risks. A destructive mistake in a script could affect hundreds or even thousands of servers, causing data loss or system failures. That is why scripts should always be checked and tested before deployment.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash scripting uses commands and variables to perform tasks step by step, while Docker Compose uses YAML configuration to define and manage multiple containers and services.

From Laboratory 1 to Laboratory 9, I gained experience with Linux commands, cloud infrastructure, virtualization, containers, object storage, deployment, monitoring, security, and automation. These activities helped me understand how different cloud technologies work together in real-world environments.

Among the different cloud engineering roles, I enjoyed the Cloud Automation Engineer role because I learned how to create scripts and schedule tasks without requiring manual execution. It was interesting to see how a simple Bash script could automatically create backups and help protect important data.

Overall, this laboratory activity helped me understand that Cloud Computing requires not only technical knowledge but also proper planning, security, monitoring, and automation. I am more confident now in using Linux and managing basic cloud operations.
