# 📝 Reflection

During this activity, I learned that cloud infrastructure is made up of different components that work together to provide a functional system. At first, I was unfamiliar with some of the Linux commands and the information they displayed. After exploring the KillerCoda Linux environment, I became more comfortable checking the system’s CPU, memory, storage, network interfaces, and operating system.

For me, **compute resources** are the most important cloud infrastructure component because they provide the processing power needed to run applications and workloads. Without CPU and RAM, the other resources would not be able to perform their tasks effectively. I also learned that cloud computing makes compute resources flexible because virtual machines can be given resources depending on the workload.

**Linux supports cloud computing** by providing a reliable and flexible operating system for servers and virtual machines. In the KillerCoda environment, I used Linux commands to check the system configuration. I found that the environment was running **Ubuntu 24.04 LTS**, using a Linux kernel and a KVM-based virtualized environment. This helped me understand how Linux can serve as the foundation of cloud infrastructure.

I also realized why **technical documentation is important** before deploying infrastructure. Documentation helps us understand what needs to be configured, keeps important information organized, and makes troubleshooting easier. It also helps prevent mistakes and allows other people to understand or reproduce the setup.

Throughout this activity, I learned new skills such as using basic Linux commands, checking system resources, understanding network interfaces, examining storage, and identifying the operating system and kernel. I also learned how compute, storage, networking, and the operating system work together.

Finally, my **GitHub portfolio improved** because I was able to document my cloud learning and organize my work into a project. It now shows not only my technical work but also my ability to investigate a Linux environment, document findings, and explain basic cloud infrastructure concepts.
