# ☁️ Cloud Infrastructure Components

## 🧠 1. Compute

Compute provides the processing power required to run applications and services.

In our KillerCoda environment, the CPU and CPU cores represent the available compute resources.

### Why does it matter?

Without compute resources, applications would not have the processing power needed to execute tasks.

---

## 💾 2. Storage

Storage is responsible for keeping data, applications, operating system files, and configurations.

In our environment, the disk represents the available storage resource.

### Why does it matter?

Applications need storage to save and retrieve information.

---

## 🌐 3. Networking

Networking allows computers, servers, and applications to communicate with each other.

The server's network interface and IP address provide connectivity.

### Why does it matter?

Without networking, users and cloud services would not be able to communicate with the server.

---

## 🐧 4. Operating System

The operating system manages the server's hardware and provides an environment where applications can run.

Our environment uses Linux.

### Why does it matter?

The operating system acts as the bridge between the hardware and applications.
