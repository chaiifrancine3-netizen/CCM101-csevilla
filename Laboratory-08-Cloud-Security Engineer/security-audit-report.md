
# Checkpoint 2 – Security Best Practices

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their assigned tasks. It is important in cloud environments because it prevents unauthorized access and reduces the risk of security problems.

## 2. Attack Surface

An attack surface refers to all the possible entry points that attackers can use to access a virtual machine or system. Examples include open network ports, running services, and weak user accounts.

## 3. Default Deny Policy

A Default Deny Policy blocks all incoming network traffic unless it is specifically allowed. It is safer because only trusted and necessary connections can access the server instead of allowing everything and trying to block attackers individually.
