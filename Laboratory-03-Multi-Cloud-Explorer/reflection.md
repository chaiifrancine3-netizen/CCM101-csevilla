# 🔵 Mission Reflection

---

This laboratory activity helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. Before completing this activity, I knew that these companies provided cloud services, but I did not fully understand how their services could be used for different business requirements. After researching the three platforms, I learned that each provider has its own strengths and services.

The cloud platform that impressed me the most was AWS. I found AWS interesting because it provides a very wide range of services for computing, storage, databases, networking, security, and application development. I also learned that AWS has a global infrastructure that can support applications in different locations.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, storage, databases, networking, identity management, Kubernetes, monitoring, and other cloud services. They also allow organizations to scale resources based on their requirements instead of depending only on physical servers.

Business requirements are very important when selecting a cloud provider. A company should consider its existing technologies, budget, application requirements, performance needs, security requirements, and future growth. For example, Azure is a good choice for an organization that already uses many Microsoft technologies, while Google Cloud can be a strong option for AI, machine learning, and data-related workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The provider should be selected based on the actual needs of the client. I also learned how to compare equivalent services between different providers.

Finally, this mission improved my GitHub Cloud Computing Portfolio because I added organized research, comparison tables, recommendations, and documentation. It also helped me practice using Markdown and presenting technical information in a more professional way.
