## 🔷 Questions

### 🔹 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services. It provides services covering computing, storage, databases, networking, security, analytics, containers, machine learning, and many other areas.

### 🔹 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations that already use Microsoft technologies. It works closely with Windows Server, Microsoft 365, Microsoft Entra ID, SQL Server, and other Microsoft products.

### 🔹 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes. Its services include AI and data tools as well as Google Kubernetes Engine (GKE).

### 🔹 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a wide range of services and is useful for many different types of applications. It would also give me an opportunity to learn many cloud technologies, including virtual machines, storage, databases, networking, and security.
